Demo

So pflegst du die neue Club-Website

Hier kannst du ausprobieren, wie sich das Bearbeiten anfühlt: Texte ändern, Termine anlegen, Bilder hochladen. Das Design bleibt dabei immer gleich, du kannst nichts kaputt machen.

Demo öffnen
  1. Auf „Start Demo“ klicken. Ein Login brauchst du hier nicht.
  2. Links eine Rubrik wählen: Seiten, Termine oder Neuigkeiten.
  3. Einen Eintrag öffnen und Text ändern. Rechts siehst du sofort die Vorschau.
  4. Ein Bild hochladen, einen neuen Termin anlegen, speichern.
  5. Auf der Startseite unter Abschnitte einen Abschnitt hinzufügen, z. B. „Bild und Text“ oder eine Fotogalerie, die Reihenfolge ändern oder einen entfernen. Die Vorschau zeigt hier nur die Felder; auf der echten Seite erscheint jeder Abschnitt im fertigen Design.

Nur zum Ausprobieren. Alles, was du hier änderst, bleibt in deinem Browser und wird nirgends veröffentlicht. Bei der echten Website meldest du dich an, und nach dem Speichern ist die Änderung etwa eine Minute später online.
