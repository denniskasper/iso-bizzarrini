# No forced password rotation

The original description required members to choose a new password every twelve months, with
no reuse. We have deliberately dropped it, and this is recorded so it is not reintroduced as
a fresh good idea.

Forced rotation is no longer recommended practice — people respond by incrementing a digit or
writing the password down, and the population hurt most is occasional users who sign in a few
times a year, which is exactly this membership. The archive is also a low-consequence target:
a stolen password reads parts data, and Contributions are checked before publication anyway.

Instead: a ten-character minimum with no composition rules, new passwords checked against
known-breached lists, self-service reset by e-mailed single-use link, rate-limited sign-in,
and long sessions with an explicit sign-out for shared computers.
